# 모델 카드 — HalluGate 판정기 v1.0

> **동결일 2026-11-25.** 게이트웨이가 배포에서 쓰는 판정기의 사양·학습·성능·한계를 한곳에 모은 문서다.
> 수치는 모두 실측이며 출처 실험 ID를 붙였다(상세는 [SSOT.md](../SSOT.md) §5). 이 문서의 값을 바꾸려면 새 버전(v1.1 등)을 만들고 SSOT 결정 기록에 남긴다.

## 1. 한 줄 요약

RAG 응답의 **문장(또는 문장 앞부분)이 근거 문서에 뒷받침되는지**를 점수(logit, 클수록 환각)로 내는 경량 판정기 2개의 조합.
영어 RAGTruth로 학습했고, 게이트웨이가 스트리밍 중 8토큰마다 호출한다.

## 2. 구성

| 항목 | 값 |
|---|---|
| 이름·버전 | `judge_combo` v1.0 (실험명 I3 조합) |
| 하위 판정기 F | **F1 base** — `cross-encoder/nli-deberta-v3-base`에서 미세조정, 이진 분류. 입력 = [근거 조각, 응답의 판정 지점까지 문장 앞부분], 최대 512토큰. 근거는 40단어 조각으로 나눠 `all-MiniLM-L6-v2` 임베딩으로 문장과 가까운 조각 8개(k=8)를 원문 순서로 이어 붙임 |
| 하위 판정기 I | **I2** — `tasksource/ModernBERT-large-nli`에서 미세조정. 입력 = [근거 전체, 응답 처음부터 판정 지점까지], 최대 2,048토큰(넘치면 근거 뒤쪽을 자름), 검색 없음 |
| 조합 방식 | 두 점수를 각각 cal-L 멀쩡한 응답 분포로 표준화한 뒤 평균. F: 평균 −3.679, 표준편차 2.187 / I: 평균 −4.456, 표준편차 2.401 |
| 재판정 간격 | 문장 시작부터 tiktoken `cl100k_base` **8토큰마다** 앞부분 판정 + 문장 끝 판정 |
| 서비스 임계값 | **B = 2.7385** (최신 LLM 응답 cal-M의 멀쩡한 응답 10% 등각 보정, K2 사전 규칙). 참고 A = 2.992(RAGTruth cal-L 서비스 10%) |
| 출력 | 조합 점수(logit 척도). 임계값 이상이면 환각 표시 |
| 실행 환경 | GPU 전제(fp16 저장, float32로 불러옴). 두 판정기를 CUDA 스트림 2개로 동시 실행 |
| 설정 파일 | [`configs/judge_combo_v1.json`](../configs/judge_combo_v1.json) (게이트웨이 `JUDGE_MODEL_DIR` 폴더의 `judge_config.json`), 구현 `hallugate/judge.py` `ComboJudge` (SPEC §4) |

## 3. 학습 데이터

## 5. 쓰임새와 범위

- **맞는 상황**: 근거 문서가 주어진 영어 RAG 응답(문서 QA, 요약, 표·데이터를 글로 옮기기)에서 응답이 근거와 어긋나는지
- **범위 밖**: 근거 없는 세계 지식 오류(사실성), 영어가 아닌 응답(게이트웨이가 검증하지 않고 통과), JSON·코드 출력

## 6. 한계 (알려진 것)

1. **최신 LLM의 환각을 많이 놓친다** (탐지 14~19%). 놓친 것의 약 68%는 근거 단어를 그대로 쓰면서 누가 무엇을 했는지만 바꾼 **직접 모순**이다(M1a). 합성 모순 재학습(K1)과 최신 LLM 실제 응답 재학습(K2) 모두 기준(+0.10)에 미달해 이 버전에 반영하지 않았다
2. **근거에서 계산해 낸 수치**(성장률로 역산한 작년 매출, 직원당 매출 등)를 근거에 없는 내용으로 보고 표시한다(H8 실측에서 반복 관찰). RAGTruth 정의와는 맞지만 사용자에게는 오경보로 보일 수 있다
3. **정답 기준이 Claude 계열**: 학습 정답 보정(Sonnet)과 평가 정답 보정·최신 LLM 정답(Opus)이 같은 계열이라 그 기준을 외웠을 가능성이 있다. 사람 점검(30개)은 아직 하지 않았다
4. **Summary가 상대적으로 약하다**(dev-L 0.266)
5. 학습 데이터 응답은 2023년 무렵 LLM 6종이라 최신 모델의 문체·오류 유형과 다르다
6. RAGTruth **test 분할 최종 평가(S5) 전**이다. 위 dev-L 수치는 개발 평가 세트 기준이다
